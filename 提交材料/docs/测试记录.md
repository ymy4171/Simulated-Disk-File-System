## 5. 调试历史与限制

第一轮 21 项测试出现 2 项 Windows 文件锁导致的外部读失败，调整测试读取时机后复测。另补了跨用途缓冲一致性回归和 HTTP 测试。沙箱限制导致一次完整运行失败，正常本机获准运行后 23 项通过，未隐藏这些环境失败。

未测试/未实现：断电恢复、任意 Windows/JDK 发行版兼容性、超出单机回环访问的网络环境。浏览器加载后不持续轮询其他页面变更，需手动刷新。最终构建不代表拥有数据库事务级崩溃一致性。
