# 桌面版使用说明

## 运行

- 免安装版：双击 release/desktop/FatLab/FatLab.exe。必须保留整个 FatLab 文件夹，不能只复制 EXE。
- 安装版：运行 release/desktop/FatLab-1.1.0.exe，按向导安装。已配置当前用户安装、桌面快捷方式和开始菜单入口。
- 两者均附带 Java 运行环境，不需要另装 Java。适用于 Windows x64。
- 原 start.cmd 仍启动浏览器版。

## 数据与操作

桌面版默认磁盘在 %LOCALAPPDATA%/FatLab/disk.img，底部显示实际路径。首次运行点击“初始化磁盘”并确认。后续操作与《课设要求逐项演示手册》一致。

点击窗口右上角关闭，程序会关闭打开文件、写回缓冲区并停止本地服务。保存失败时窗口保留并提示错误。输入框中尚未点击“追加写入”的文本不属于已写入文件，退出前请先提交。强制结束进程或断电不保证保存。

桌面版自动使用本机空闲端口，不与浏览器版固定 8080 端口冲突。不要让两个程序同时打开同一个磁盘镜像。

## 迁移原有磁盘

1. 在浏览器版点击“关闭全部并保存”，然后运行 stop.cmd。
2. 关闭桌面版。
3. 备份 D:/keshe/data/disk.img 和桌面版已有镜像。
4. 将原镜像复制到 %LOCALAPPDATA%/FatLab/disk.img，再启动桌面版。不要点击重新初始化。

未自动迁移或覆盖现有演示数据。测试数据只位于 target/desktop-check。

## 构建

使用 Java 21、Maven 运行 build-desktop.cmd。脚本构建、测试并用 jpackage 生成带运行环境的桌面目录。若 PATH 包含 WiX 3 的 candle.exe/light.exe，则继续生成安装包。本项目临时构建工具位于 target/wix；打包前可临时将该目录加入 PATH。输出目录带时间戳。
