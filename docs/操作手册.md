# 操作手册

## 1. 启动、初始化、退出

运行项目根目录 `start.cmd`，等待自动打开浏览器。第一次运行显示“准备你的模拟磁盘”，点击“初始化磁盘”并确认。初始化完成后应显示空闲盘块 123、打开文件 0；0～2 是系统块，23 和 49 是坏块。

已有镜像会先检查大小、FAT、目录结构、结束符、循环链、共享块及孤立块。校验失败会显示错误，不会重建或覆盖。需要重新开始时，先停止服务并备份 `data/disk.img`，再启动并点击页脚“重新初始化磁盘”。有打开文件时必须先关闭。

正常结束：点击顶部“关闭全部并保存”，然后运行 `stop.cmd`。关闭网页不等于停止后端；浏览器离开提醒也不是保存操作。手动前台启动时可在保存后 Ctrl+C 退出。

## 2. 完整操作示例

1. 在“绝对路径”填写 `/doc`，点击“创建目录”。左侧出现 doc，空闲数变为 122。
2. 双击目录行或点击目录树 doc，进入 `/doc`。
3. 路径填 `/doc/a.tx`，属性选“4 · 普通读写”，点击“创建文件”。系统自动以写模式打开，打开表增加一行。
4. 在读写实验区填 `hello`，写入字节数留空，点击“追加写入”。观察写指针为起始块偏移 5，数据缓冲为 DIRTY。
5. 点击“关闭文件”，末尾写入 `#`，缓冲写回，打开表移除该项。
6. 点击“显示内容”，输出 `hello`，字节数为 5；展开十六进制查看 `68 65 6c 6c 6f`。
7. 读取字节数设 2，点击“读取文件”：自动以读模式打开，输出 `he`。再次读取输出 `ll`，读指针连续前进。
8. 点击“关闭文件”。写入内容换成 `!`，点击“追加写入”，再关闭。显示内容应为 `hello!`。
9. 文件关闭时将属性选为“5 · 普通只读”，点击“修改属性”。写入会被拒绝；改回 4 后可继续追加。
10. 点击“删除文件”并确认，整条文件链被回收。路径换成 `/doc`，点击“删除空目录”并确认，空闲盘块恢复 123。

## 3. 按钮与限制

| 操作 | 输入 | 规则 |
|---|---|---|
| 创建目录 | 绝对路径 | 父目录必须存在，每个目录最多 8 项 |
| 列目录 | 目录路径 | 在操作输出中显示登记项 |
| 删除空目录 | 目录路径 | 不允许根目录或非空目录 |
| 创建文件 | 路径、属性 | 不可创建只读文件，自动写打开 |
| 打开文件 | 路径、r/w | 最多 5 项，同模式重复打开不增加登记 |
| 读取文件 | 路径、字节数 | 自动读打开，从当前指针开始；0～8192 字节 |
| 追加写入 | 路径、内容、可选字节数 | 自动写打开，不超过内容字节数，禁止 # |
| 关闭文件 | 路径 | 写模式写入结束符并更新目录项；未打开时无操作 |
| 显示内容 | 路径 | 文件必须关闭，不改变打开表 |
| 删除文件 | 路径 | 文件必须关闭，回收全部文件块 |
| 修改属性 | 路径、属性 | 文件必须关闭 |

普通读写 4、普通只读 5、系统读写 2、系统只读 3。系统属性是教学标记，不意味着禁止删除。文件目录同名（完整名称相同）被拒绝，名称区分大小写。主体 1～3 字节，扩展名可省略或为 1～2 字节；仅非空白 ASCII，禁止 `$`、`.`、`/`、反斜杠出现在名称字段中，点仅用于分隔扩展名。路径须从 `/` 开始，不支持 `..`、重复斜杠、末尾斜杠及相对路径。

文件内容使用 UTF-8。中文通常占多个字节，界面会显示实际字节数。按字节读取可能截断字符，系统会显示“包含不完整 UTF-8 字符”并保留原始十六进制；这不是数据丢失。写入长度不填时写入全部内容，手动指定长度也可能截断字符。

## 4. 查看内部状态

- 点击文件行，高亮它的 FAT 链。例如 128 字节需要三个块，因为第 129 个字节是 `#`。
- 点击盘块查看块号、FAT 值和 64 字节内容；若该块在缓冲中，以缓冲中的最新内容展示。
- 打开表中的字节长度不含结束符。指针形式为“盘块号 : 块内偏移”。目录列表的盘块数在关闭时更新，写入过程中 FAT 高亮可能已增长。
- buffer1 用于 FAT 与目录，buffer2 用于文件数据；DIRTY 表示尚未写回，CLEAN 表示缓存与镜像同步。共享缓冲在切换块时自动写回。
- 操作轨迹保留最近 180 条事件。刷新仅查询快照，不把脏缓冲强制写回。多个浏览器页面共享一个文件系统状态，其他页面需点击“刷新”。

## 5. 常见问题

| 提示 | 处理 |
|---|---|
| 端口 8080 已被占用 | 已启动时直接访问；本项目用 stop.cmd 停止，其他程序不要强杀 |
| Java 21 required | 安装 JDK 21 并配置 PATH |
| 缺少 release/fat-lab.jar | 运行 build.cmd，或恢复完整交付目录 |
| 文件已打开 | 关闭后再显示、删除或改属性 |
| 请先关闭再切换模式 | 读打开不能写、写打开不能读 |
| 目录已满 | 换父目录，或删除不需要的项 |
| 空间不足 | 删除已关闭文件释放空间；失败写入不执行部分追加 |
| 磁盘加载失败 | 停止服务、备份镜像，检查损坏原因；不要直接格式化重要演示数据 |
| 连接失败 | 查看 data/server.log 和 server-error.log，确认服务未停止 |

格式化仅作用于配置的模拟镜像，不操作磁盘分区。不要在服务运行中用外部编辑器改镜像。
